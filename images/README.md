# Project Image Assets and Dashboard Screenshots

This directory stores visual assets and screenshots referenced directly in the project README and technical documentation.

## Recommended File Names and Visual Contents

1. `customer_overview.png`
   - Purpose: Visual preview of Report Page 1 (Customer Overview).
   - Recommended resolution: 1280 x 720 or 1920 x 1080.
   - Highlights: 6 executive KPI cards, customer count by segment, retention distribution donut, category/channel breakdowns.

2. `segmentation_and_value.png`
   - Purpose: Visual preview of Report Page 2 (Segmentation and Customer Value).
   - Recommended resolution: 1280 x 720 or 1920 x 1080.
   - Highlights: Diagnostic spend metrics, segment revenue share donut chart, combo chart of revenue and customer counts by loyalty tier.

3. `retention_and_risk.png`
   - Purpose: Visual preview of Report Page 3 (Retention and Risk Scorecard).
   - Recommended resolution: 1280 x 720 or 1920 x 1080.
   - Highlights: Risk scorecard cards, segment by loyalty tier risk matrix, customer-level drill-down audit table.

4. `web_companion_preview.png`
   - Purpose: Visual preview of the custom web companion dashboard running at http://localhost:8080.
   - Recommended resolution: 1280 x 720 or 1920 x 1080.
   - Highlights: Midnight Slate glassmorphic layout, dynamic search box, multi-slicers, and Chart.js dual-axis canvas visual.

## Asset Guidelines

- Format: PNG, WebP, or SVG.
- File size: Keep images compressed under 2 MB each for optimal web loading.
- Aspect ratio: 16:9 standard canvas aspect ratio.
